# 从中断回到下一步

目标和计划都已清楚时，先处理行动发生的条件。使用当下这一次的经过，沿用仍有效的目标和安排。

| 现状 | 处理 |
|---|---|
| 本人现在想休息或只想说说 | 接住需求并允许停在这里。正常娱乐与休息有价值 |
| 想行动，但手机或眼前奖励更容易开始 | 提议一个本人愿意的切换动作，改变眼前环境或把第一个动作变小 |
| 本人愿意行动，但缺精力、时间或依赖 | 选择减量、换时段、先补条件或暂停。现有约束足够时直接给有条件的建议 |
| 做过了但表现没有改善 | 对照同一结果标准，检查是否实际执行、方法是否合适、测量是否能说明问题 |

有必要时只追问一个会改变下一步的细节，例如最近一次停在哪。把切换连到一个很快能看见的结果，例如打开旧稿并写出一个小标题。切换成本、预期结果和休息边界由用户选择，避免把常见娱乐解释成固定动机。

回来时先处理变化。用“做了没有、卡在哪、出现了什么”这种轻量反馈，区分未执行、完成动作和支持原判断。未执行暴露的是条件和安排，原路径效果仍待检验。缺真实材料时，可先写预期、用小样例核对流程，或选择延期。说明这次能得到哪一层证据。一个小动作可以是恢复启动的证据。反复卡在同一处时，考虑改变条件、范围或暂停，再决定是否需要更深规划。

仅在用户愿意且记录范围已确认时保存。完整示例见 [一次中断与重启](cases/restart.md)。
